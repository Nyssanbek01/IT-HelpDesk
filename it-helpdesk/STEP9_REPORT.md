Шаг 9 — итоговый отчёт, 13 октября 2026

Frontend загрузки, скачивания и удаления вложений завершён для user, engineer и admin. Общий компонент `frontend/src/components/TicketAttachments.tsx` подключён через `TicketActivity` на страницы заявки всех трёх ролей. Исходники backend, API, схема и миграции не изменялись.

Реализовано:

- Список вложений с именем, размером, автором, датой и счётчиком до 10 файлов; состояния загрузки, пустого списка, ошибки и повторной попытки.
- Загрузка одного файла через FormData (`file`) с Bearer-токеном. Проверка непустого файла, расширения и размера до 10 МБ; разрешены PNG, JPG/JPEG, WEBP, PDF, TXT, DOCX. Проверку содержимого выполняет существующий backend.
- Авторизованное скачивание через fetch и Blob с исходным именем. Токен не попадает в URL; объектный URL освобождается после передачи браузеру.
- Удаление с подтверждением: user и engineer видят кнопки для своих вложений, admin — для любых. Сервер остаётся источником окончательного решения о правах.
- Блокировка повторных операций, отмена запросов при размонтировании, сообщения ошибок, очистка сессии и переход на login при 401.
- Обновление истории после загрузки и удаления; русские названия событий attachment_added и attachment_deleted. После ошибочного ответа на изменение список перечитывается, поскольку изменение могло уже сохраниться на сервере.
- Адаптивный интерфейс, проверенный при ширине 375 px.
